# Planning for SafeKeep

## Planning for project development for SafeKeep

## App Name: SafeKeep

#### What kind of app is SafeKeep?

- SafeKeep is a terminal application designed to store user credentials securely.
- Users can add, edit, and delete credentials.
- SafeKeep can also generate secure passwords for users.
    - Users will be able to specify requirements for generated passwords.
- Users will be able to recover their accounts with a recovery phase which will be generated at the time of account
  initialization and given to the user.

#### Essential Features

- Users can create an account
- Users can log in and see stored passwords
- Users can select to view a credential, which will initially be encrypted
    - Users will be able to decrypt the credential using a PIN.

#### Optional Features

- Users can update their `username`
- Users can update their `PIN`
- Users can remove the password timer for specified credential
- Users can update their `password`
- Delete Account

#### How the Team will work

- Team will meet on discord and work using pair programming in the beginning to lay the foundations together.
- Afterward during implementation team members will do more individual work and meet on discord to review what has been
  done.
    - During these meetings pair programming sessions will take place.

#### How do we determine that the project is completed and how do we determine that the features / user stories are complete?

- For Features and User Stories
    - Once the acceptance criteria is met, and the test cases are passed, then the feature / user stories are complete
- For Project Completion
    - Once all features and user stories are completed, then the project is Completed.
    - Additional backlog features are non-required functionality that will improve usability but not impact
      functionality.
