Story 1 (Essential):<br>
I as a User want to be able to create a new account so I can log in.<br>
Acceptance Criteria:<br>
Account is created successfully as well as the User is able to log in.

Story 2 (Essential):<br>
I as a User want to be able to log in so I can access my stored passwords.<br>
Acceptance Criteria:<br>
User is able to log in successfully and see the list of stored passwords.

Story 3 (Essential):<br>
I as a User, when I select a password to view, it is initially encoded/encrypted.<br>
Acceptance Criteria:<br>
When a User selects to view the password, it is not in plain text.

Story 4 (Negative US):<br>
I as a User want an error message to be displayed when an invalid password is entered.<br>
Acceptance Criteria:<br>
When a User enters an invalid password, an error message is displayed.

Story 5:<br>
I as a User want to see my selected password unencrypted after entering a PIN.<br>
Acceptance Criteria:<br>
User is able to view their stored password in plain text after entering a valid PIN.

Story 6:<br>
I as a User am able to see which websites share the same username/password combination.<br>
Acceptance Criteria:<br>
User is able to see which websites share the same username/password combination.

Story 7:<br>
I as a User am able to generate a new password based on a set of criteria.<br>
Acceptance Criteria:<br>
User is able to generate a new password based on a set of criteria.

Story 8:<br>
I as a User want to be able to retrieve my account using the given recovery phrases given during account creation.<br>
Acceptance Criteria:<br>
User is able to retrieve their account using the given recovery phrases.

Story 9:<br>
I as a User want to be able to set an expiree date / configured time reminder for any given password.<br>
Acceptance Criteria:<br>
User is able to set an expiree date / configured time reminder for any given password.

Story 10:<br>
I as a User want to be able to remove the expiree date / configured time reminder for any given password.<br>
Acceptance Criteria:<br>
User is able to remove the expiree date / configured time reminder for any given password.
