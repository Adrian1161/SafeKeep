# User Stories

## Story 1 (Essential):
I as a User want to be able to create a new account so I can log in.
### Acceptance Criteria:
Account is created successfully as well as the User is able to log in.

## Story 2 (Essential):
I as a User want to be able to log in so I can access my stored passwords.
### Acceptance Criteria:
User is able to log in successfully and see the list of stored passwords.

## Story 3 (Essential):
I as a User, when I select a password to view, it is initially encoded/encrypted.
### Acceptance Criteria:
When a User selects to view the password, it is not in plain text.

## Story 4 (Negative US):
I as a User want an error message to be displayed when an invalid password is entered.
### Acceptance Criteria:
When a User enters an invalid password, an error message is displayed.

## Story 5:
I as a User want to see my selected password unencrypted after entering a PIN.
### Acceptance Criteria:
User is able to view their stored password in plain text after entering a valid PIN.

## Story 6:
I as a User am able to see which websites share the same username/password combination.
### Acceptance Criteria:
User is able to see which websites share the same username/password combination.

## Story 7:
I as a User am able to generate a new password based on a set of criteria.
### Acceptance Criteria:
User is able to generate a new password based on a set of criteria.

## Story 8:
I as a User want to be able to retrieve my account using the given recovery phrases given during account creation.
### Acceptance Criteria:
User is able to retrieve their account using the given recovery phrases.

## Story 9:
I as a User want to be able to set an expiree date / configured time reminder for any given password.
### Acceptance Criteria:
User is able to set an expiree date / configured time reminder for any given password.

## Story 10:
I as a User want to be able to remove the expiree date / configured time reminder for any given password.
### Acceptance Criteria:
User is able to remove the expiree date / configured time reminder for any given password.
